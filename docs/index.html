Session Keeper for eRA Commons (unofficial)

Session Keeper for eRA Commons is a small Chrome extension that keeps your own, already-signed-in NIH eRA Commons session from timing out while you're reading instead of clicking. It sends eRA's own page a harmless activity signal every few minutes and presses eRA's own "Continue" button if a timeout warning appears.

Not affiliated with NIH or eRA. This is an independent, unofficial project.
