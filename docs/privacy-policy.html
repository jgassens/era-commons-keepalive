Privacy Policy — Session Keeper for eRA Commons (unofficial)

Last updated: September 25, 2026

This extension is unofficial and is not made by, operated by, or affiliated with NIH or eRA Commons in any way. It is a small independent browser add-on that helps keep your own, already-signed-in eRA Commons session from timing out.

Who made this

Maintainer: Jeremiah Gassensmith
Contact: jgassens@gmail.com

What this extension does

While it is turned on and an eRA Commons browser tab is open, it sends that page a harmless scroll signal every four minutes so eRA's own page script treats you as active, and it presses eRA's own on-screen "Continue" button if a timeout warning appears. By default it also calls eRA's own keep-alive address on eRA's own site (see "The one network call" below). That is the whole job.

What data it handles

Everything below stays on your own computer, in your own browser's local storage. It is never uploaded to a server, never shared with any third party, and there is no account, sign-in, or analytics system run by the maintainer.

  • Session status and timestamps — whether you appear signed in, and the last few times the extension nudged the page or clicked a warning.
  • eRA's own timeout cookie (ERA_SESSION_TIMEOUT_COOKIE) — read only to know when eRA itself will end your session, and watched only to notice the moment eRA deletes it (which is how eRA signals that you have been logged out). The extension only looks at this one cookie's name and expiry time; it does not read or store any other cookie, on eRA or anywhere else.
  • A local diagnostic log — up to 200 lines of page paths (with any query string, page fragment, or session ID stripped out), timestamps, and short event descriptions, kept only so you can see what the extension has been doing. It never records page content, form fields, or credentials of any kind.

What it never does

  • It never logs you in, and cannot log you in on your behalf.
  • It never reads, stores, fills in, or transmits your username, password, two-factor code, or any other credential.
  • It does not use analytics, tracking pixels, or any third-party service.
  • It does not run any code that is downloaded at runtime — every script it runs ships inside the extension package itself.

The one network call

The popup has a switch labeled "Also ping eRA's server." It is on by default, and you can switch it off at any time. While it is on, the extension calls eRA's own keep-alive web address directly — the same address eRA's own page already calls on its own every 40 minutes — because eRA's server can end a session it has not heard from in about an hour even while eRA's page timer is still running. This call goes only to an https://*.era.nih.gov address that eRA itself already serves; it never goes anywhere else, and it carries nothing from the extension beyond what your browser already sends to eRA. With the switch off, no such call is made and the extension still nudges eRA's page.

How to delete your data

Everything this extension stores lives inside Chrome's per-extension local storage. Removing the extension (chrome://extensions → Remove) deletes all of it immediately. Nothing survives anywhere else, because nothing was ever sent anywhere else.
